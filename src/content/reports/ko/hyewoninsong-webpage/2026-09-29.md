## 요약

오늘 올라온 블로그 글 7편은 이미지 누락이나 ko/en 불일치 없이 깨끗하다. 스펙은 현재 `main` 코드와 맞췄고 소스 코드는 건드리지 않았다.

확인이 필요한 것:

- **고아 리포트 파일**: 외부 감사 작업이 `chore/daily-audit-2026-09-06` 브랜치에 `src/content/reports/` 파일을 계속 커밋하고 있다. reports 컬렉션은 PR #19 에서 없앴으므로 쓰이지 않는 파일이다. 이번에도 리포트 파일은 쓰지 않았다.
- **열린 감사 PR #22, #23**: 둘 다 옛 `main` 기준으로 `docs/specs/website.md` 를 고쳐서 이번 PR 과 충돌한다. 스펙 변경은 이번 PR 로 대체하고 닫는 쪽을 권한다. #22 의 `tests/app-screenshots.test.mjs` 는 필요하면 따로 살리면 된다.
- **graphify**: `graphify-out/` 이 메인 체크아웃에만 있는 추적되지 않는 폴더라 `graphify update .` 는 돌리지 않았다.
