- `docs/appstore-playbook/sheet-capture-recipe.md` — 삭제된 `testAllScreenshots()` 를 예시로 쓰던 "호출 위치" 섹션을 세그먼트 구조 기준으로 갱신, 테마 캡처 예시(`captureThemeStandard` 등)와 baseline 의 `theme = standard` 항목 제거, HR-S4 예시를 테마 picker 에서 일반 팝오버로 교체
- `docs/appstore-playbook/playbook.md` — Excluded features 표에 테마 시스템(#100 제거) 행 추가, HR-7(테마 picker 규칙)을 OBSOLETE 로 마킹
- `docs/design-docs/decision-log.md` 와 `fastlane/README.md` 는 커밋 내에서 이미 갱신됨. `docs/appstore-reviews/`, `docs/promo/iterations/` 의 `testAllScreenshots` 언급은 타임스탬프가 붙은 과거 기록이라 수정하지 않음
- 커밋이 앱 소스나 제품 기능을 건드리지 않아 `docs/product-specs/` 는 감사 대상 아님

- 모든 테스트가 최신 상태 — 커밋의 변경 자체가 UITest 파일(`AppStoreScreenshots.swift`)과 fastlane 설정 수정이며, 앱 소스 변경이 없어 커버리지 공백이 발생하지 않음

## 요약

커밋 1건은 App Store 캡처 파이프라인 개편으로, 코드 쪽 결정 기록(decision-log)은 커밋에 포함돼 있었지만 살아있는 가이드 문서인 캡처 플레이북 2개가 삭제된 monolith 메서드와 제거된 테마 시스템을 여전히 참조하고 있었다. 두 문서를 현재 세그먼트 구조에 맞게 갱신했고, 향후 캡처 에이전트가 존재하지 않는 메서드/기능을 따라가는 일을 방지했다. 테스트 추가는 불필요. 참고로 working tree 에 진행 중인 미커밋 캡처 리팩터링이 있어, 문서는 세그먼트 개수/이름 변경에 견디도록 구조 중심으로 서술했다.
