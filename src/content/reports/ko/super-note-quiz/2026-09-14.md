## 오늘의 변경 사항

최근 24시간 내 21개 커밋 (병합 포함). 주요 기능: 홈 헤더/계정 선택기/기록 화면 재구성(915cf9e), 정답 원 마크 시계방향 수정(9d82c2e), 마커펜 채점 표시(bf5c50f), 문제 카드 스택 연출(cbe56d9), 선택 답안·문제 번호·그룹 히스토리 표시(6dec082), 온음표 문제 추가(b8169c2), Icon Composer 앱 아이콘 번들 추가, TestFlight 빌드 번호 ASC 연동 수정 등.

## 문서 감사 결과

모든 문서가 최신 상태 — 해당 커밋들이 코드와 같은 커밋 안에서 ADR-0016/0017/0018/0019, `docs/architecture/screens.md`, `docs/architecture/record-storage.md`, `specs/screens.md`, `specs/quiz-flow.md`, `docs/conventions/ui-principles.md` 를 이미 갱신했음. `ClefSelectionView.swift`, `AccountCard.swift`, `RecordView.swift`, `GradeMarkView.swift`, `QuestionCardStack.swift` 등 실제 소스와 대조 검증 완료, 불일치 없음.

## 테스트 감사 결과

- `NoteQuizTests/NoteQuizTests.swift` — `AccountTests.hasKnownCreationDate()` 추가. `915cf9e`에서 새로 생긴 `Account.hasKnownCreationDate`(AccountCard의 "만든 날 기록 없음" 분기를 구동)에 직접 검증이 없어서 보강. `-only-testing:NoteQuizTests/AccountTests` 통과 확인.
- 짚었지만 손대지 않은 항목: `QuestionCardStack.swift`, `GradeMarkView.swift` 는 렌더링/애니메이션 로직이라 `docs/conventions/testing.md` 의 테스트 범위(모델·영속성 계층)에 해당하지 않아 테스트 미추가. `FeedbackState` 의 `Equatable → Hashable` 전환은 사소한 프로토콜 준수 변경이라 테스트 불필요로 판단.

## 요약

하위 에이전트가 21개 커밋을 문서/스펙/테스트 관점에서 감사한 결과, 문서·스펙은 이미 코드와 함께 갱신되어 있었고 계정 관련 헬퍼 하나에만 테스트 공백이 있어 보강했다. 소스 코드는 건드리지 않았으며 변경 사항은 PR #22 (https://github.com/hyewoninsong/super-note-quiz/pull/22, base: docs/marketing-assets) 로 올라가 있다.
