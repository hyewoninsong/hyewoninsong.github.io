## 문서 감사 결과

업데이트한 문서 (docs 2, specs 3):

- `docs/modules/quiz-engine.md` — 오답 피드백이 1.5초로 적혀 있었으나 코드는 0.8초(ADR-0089). VoiceOver 안내, `wrongAttemptCount`, suspend/resume/cancelPending, 설정에 따른 소리·진동 차단을 추가.
- `docs/modules/navigation.md` — 시트 루트 목록에 `SettingsSheet` 누락. 톱니 버튼과 저장 시트가 뜰 때 피드백 전환이 멈추는 동작을 추가.
- `specs/screens.md` — 설정 톱니·`SettingsSheet` 행, 통계 빈 상태의 시작 버튼, 세로 고정·모션 줄이기, 오답에만 흐림·흔들림, VoiceOver 안내, 30Hz 시계, 저장 시트 일시정지를 추가. "모든 답에 흐림" 문장을 정정.
- `specs/quiz-flow.md` — 상태 다이어그램에 `wrongAttemptCount`·안내·suspend/resume 추가. 피드백 시간을 정답 1500ms / 오답 800ms 로 정정.
- `specs/app-overview.md` — 소리·진동 토글, VoiceOver·모션 줄이기 기능 행과 세로 고정 제약 추가.

이미 최신이라 건드리지 않은 것: `AGENTS.md` 불변식, `docs/conventions/*`, `docs/architecture/*`, `docs/adr/index.md`(0107–0112 모두 등록, 중복 없음), `specs/note-data.md`, `specs/difficulty-and-clef.md`.

## 테스트 감사 결과

기존 테스트가 대부분을 덮고 있어서 빈틈만 새 파일 하나로 채움.

- `NoteQuizTests/AuditGapTests.swift` (신규, 13개)
  - `cancelPending` 이 예약된 다음 문제 전환도 끊는지 (기존엔 공개 사다리만 검증)
  - `suspendFeedback` 이 오답 해제도 붙잡는지 (기존엔 정답 뒤만 검증)
  - `ElapsedTime` 가장자리: 올림 없이 버림, 10시간 이상, 두 자리 시간 자리표시자, 음수 입력
  - `PercentFormat` 가장자리: 1 초과, 아주 작은 값, 인자 없는 프로퍼티 형태
  - `SettingsStore`: 두 키가 서로 다름, 켜짐 값이 명시적으로 기록됨

실행 결과: `vc-daily-audit-iphone-17` 시뮬레이터에서 단위 테스트 258개 통과. 첫 실행에서 이번 범위 밖의 기존 테스트 `FeedbackDurationTests/wrongFeedbackClearsBeforeCorrectWould` 가 타이밍 플레이크로 한 번 실패했고 재실행에서 통과.

테스트하지 않은 것: `SoundManager`/`Haptics` 의 `SettingsStore.shared` 게이팅(주입 불가 싱글톤), 로케일별 `ElapsedTime.text`, `Announce.post`(시스템 API 호출뿐).

## 요약

24시간 동안 피처 PR 8건과 ADR 인덱스 정리 2건이 통합 브랜치에 들어왔다. ADR·컨벤션·아키텍처 문서는 각 PR 이 같이 올려서 이미 정확했고, 뒤처진 곳은 `docs/modules/` 와 `specs/` 였다. 오답 피드백 시간(1.5초 → 0.8초)과 "모든 답에 흐림" 같은 거짓 문장을 정정하고 설정 시트·VoiceOver·세로 고정 같은 새 동작을 등록했다. 테스트는 떠나는 길(취소·일시정지)과 서식 가장자리 13개를 보강했고 전체 258개가 통과한다. 소스 코드는 수정하지 않았다.
