## 오늘의 변경 사항

- 로컬 브랜치(`improve/testflight-default-latest-branch`)에는 최근 24시간 커밋이 없어. 그래서 `origin/main` 기준으로 감사했고, 커밋은 33개(머지 커밋 포함)야.
- 코드 변경
  - `hooks/worktree-gc.sh`: `--all` 추가. 모든 레포의 워크트리를 한 번에 훑어.
  - `hooks/check-updates.sh`: 스왑이나 fseventsd 메모리가 높으면 경고해. 하루에 한 번 백그라운드로 `worktree-gc.sh --all --apply --quiet` 도 돌려.
  - `hooks/mem-gc.sh`: 새로 추가된 메모리 부족 진단 스크립트.
  - `install.sh`: `mem-gc.sh` 배포 항목 추가.
- 문서·스킬 변경: swiftui-pitfalls 쪽이 가장 많아(PDFKit, 탭바, popover 측정 루프, Text 줄바꿈 등). 나머지는 appstore-assets(캡션 폭 검사, localize_simulator, 드래그 끝점), swiftui-visual-check, disk-gc, worktree-gc 스킬, disk-hygiene, branch-strategy.

## 문서 감사 결과

- `docs/modules/hooks.md`
  - `check-updates.sh` 설명에 메모리 경고와 하루 1회 전 레포 워크트리 스윕을 넣었어.
  - `worktree-gc.sh`(`--all`, `WORKTREE_GC_REPO_ROOTS`), `disk-gc.sh`, `mem-gc.sh`, `*.test.js` 행이 표에 없어서 추가했어.
  - UserPromptSubmit 이벤트 설명도 고쳤어.
- 스킬 문서들은 변경된 스크립트와 같은 커밋에서 이미 함께 고쳐져 있어서 추가로 손댈 게 없었어.

## 테스트 감사 결과

- `hooks/worktree-gc.test.js`를 새로 만들었어. 임시 레포에서 dry-run으로만 돌리니까 진짜 워크트리는 안 건드려. 확인하는 건 이거야:
  - `--all`과 `--repo`를 같이 쓰면 exit 1로 막는지
  - 워크트리가 있는 레포만 훑고, git 아닌 폴더나 워크트리 없는 레포는 건너뛰는지
  - `:`로 구분한 루트 여러 개를 다 처리하는지
  - `--quiet`가 레포별 실행까지 전달되는지
  - 없는 루트를 줘도 에러가 안 나는지
- `node hooks/worktree-gc.test.js` 실행 결과 전부 통과했어.
- `mem-gc.sh`랑 `check-updates.sh`는 테스트를 안 붙였어. 결과가 실행하는 머신의 스왑이나 프로세스 상태에 따라 달라지고, `check-updates.sh`는 실제 `~/.claude` 상태까지 바꾸기 때문이야.

## 요약

전역 훅 3개가 바뀌었는데 `docs/modules/hooks.md`에 반영이 안 돼 있어서 문서를 맞췄어. 새로 생긴 `worktree-gc.sh --all` 스윕에는 회귀 테스트를 붙였어. 소스 코드는 안 건드렸어. 로컬 작업 트리에 커밋 안 된 변경이 있어서 `origin/main` 기준 별도 워크트리(`.worktrees/audit-2026-09-25`)에서 작업했어.
