## 요약

문서 2개를 고치고 테스트 2개를 추가했다. 소스 코드는 건드리지 않았다.

감사 중 소스 쪽 문제 3건을 찾았고, 고치지 않고 PR 본문에 적었다.

1. **다운로드 설치 목록에 빠진 훅**: `install.sh` 의 `--global` / `--update` 가 `launch-guard.js`, `shell-heredoc.js`, `simulator-lifecycle.js`, `rc-session-gc.sh`, `simctl-throwaway.py` 를 받지 않는다. 앞의 셋은 `global-settings.json` 에 등록돼 있어서, 다운로드로 설치한 머신은 없는 파일을 훅으로 부른다. 심링크 설치는 영향 없다.
2. **`simctl-throwaway.py` 가 `{"devices": null}` 입력에 exit 1**: 잡히지 않는 `AttributeError` 다. `disk-gc.sh` 는 stdout 만 읽어서 실제 영향은 진단 줄이 빠지는 것뿐이다.
3. **`background.path` 기준 경로 불일치**: `screenshot-framer.md` 는 프로젝트 루트 기준, `frame_screenshots.py` 주석은 실행 위치 기준이라고 적혀 있다.

이전 감사 PR #273, #291 이 아직 열려 있고 같은 `hooks.md` 를 고친다. 이번 `hooks.md` 는 #273 의 내용을 포함하므로 이쪽을 먼저 머지하면 두 PR 의 `hooks.md` 변경은 버려도 된다. 테스트 파일은 #140 을 포함해 이름이 달라 겹치지 않는다.
