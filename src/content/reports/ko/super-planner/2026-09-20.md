## 문서 감사 결과

- 모든 문서가 최신 상태. ADR 0001~0006, `planner-v2.md` 스펙(§3.7 반복 배치, §3.8 실행 취소 포함), 아키텍처 문서, 함정 문서가 각 커밋과 함께 갱신되어 있어 수정할 부분이 없었다.

## 테스트 감사 결과

- 추가: `todoTests/RepeatBlockTests.swift`
  - 반복 패턴(매일/평일/매주)별 날짜 계산
  - 0주 입력 시 빈 결과
  - 재실행 시 같은 시각에 이미 배치된 날은 건너뛰는지 확인
- 이전에는 `repeatBlock`을 undo 그룹 관점에서만 테스트했고, 패턴 계산과 중복 건너뛰기는 검증이 없었다.
- 새 테스트는 로컬에서 실행해 통과했다 (TEST SUCCEEDED).
- 나머지 서비스 로직은 기존 테스트가 이미 다루고 있었다.

## 요약

문서와 스펙은 코드와 일치해서 수정하지 않았고, 테스트 공백이던 반복 배치 로직만 보강했다. 소스 코드는 건드리지 않았다. PR: https://github.com/hyewoninsong/daily-planner/pull/38
