SuperFont 메인 화면 맨 아래에 광고 배너가 생겼다. 광고가 싫은 사람은 배너 바로 위 "광고 없이 쓰기 ›" 를 눌러 ₩6,600 을 한 번 내면 광고가 영영 사라진다.

## 배너는 메인 화면에만, 설치 흐름에는 없다

![메인 화면 아래, 설치 버튼 밑에 "광고 없이 쓰기" 한 줄과 테스트 배너가 쌓여 있다](/blog/superfont-ads-remove-ads/banner.png)

구성은 시간표 앱에서 가져왔다. 위에서부터 앱이 직접 그리는 한 줄("광고 없이 쓰기 · 가격 ›"), AdMob 고정 적응형 배너, 홈 인디케이터 띠다. 한 줄은 광고 영역 밖에 앱 글자로 둔다 — 광고처럼 보이는 탭 요소를 광고에 겹치면 AdMob 정책에 걸린다. 광고가 오지 않으면(무충전, 오프라인, 동의 거부) 빈 띠 대신 같은 자리에 앱 자체 배너를 띄운다. 자리를 접으면 동의 거부가 곧 광고 없음이 되어 결제할 이유가 사라지고 화면도 튄다.

배너는 메인 화면과 세로로 쌓았다. 그래서 메인 화면 높이 자체가 줄고, 하단의 "N개 설치" 버튼이 배너 바로 위에 선다. 폰트를 설치하는 위저드는 전체 화면으로 덮이니 설치 도중에는 광고가 없다.

동의는 Google 권장 순서 그대로 UMP 동의 → 앱 추적 투명성(ATT) → SDK 시작이고, 스플래시가 걷힌 뒤에 묻는다. 세리프 A 가 갈라지는 연출 위에 시스템 창이 겹치면 첫인상이 권한 창이 된다.

## 결제 창 대신 시트를 연다

![광고 없이 쓰기 시트 — 앱 마크와 설명, 광고 제거 버튼, 구매 복원, 안내 문구](/blog/superfont-ads-remove-ads/remove-ads-sheet.png)

시간표 앱은 "광고 없이 쓰기" 를 누르면 바로 결제 창이 뜬다. 구매 복원과 광고 개인정보 설정은 설정 화면에 있다. SuperFont 에는 설정 화면이 없다. 그런데 둘 다 빠뜨릴 수 없다 — 한 번 사는 상품은 앱 안에 복원 버튼이 있어야 심사를 통과하고, 동의를 받는 지역에서는 사용자가 동의를 바꿀 길이 앱 안에 있어야 한다.

고른 길은 진입점이 시트를 여는 것이다. 시트에 구매 버튼, 구매 복원, 그리고 동의 지역에서만 보이는 광고 개인정보 설정을 모았다. 결제까지 탭이 하나 늘어나는 값을 치렀다.

진 대안은 둘이다. 메인 화면 어딘가에 "구매 복원" 을 따로 두는 것은 탭 바와 설치 버튼이 이미 꽉 찬 화면에 자리가 없었다. 설정 화면을 새로 만드는 것은 이 기능 하나에 비해 너무 컸다.

시트 안 카드의 아이콘도 한 번 바꿨다. 처음엔 SF Symbol `textformat` 을 썼는데, 이 심볼은 한국어에서 "가가" 를 그린다. 빈 화면에선 어울리지만 광고 제거 카드에선 무슨 뜻인지 알 수 없어, 스플래시의 세리프 A 로 바꿨다. 카드의 가격 캡슐도 뺐다 — 바로 아래 큰 버튼이 같은 말을 한다.

## 배너를 쌓은 한 줄이 편집 바를 키보드 밑에 깔았다

배너를 붙인 뒤 키보드를 올려 보니 배너가 키보드 위로 밀려 올라와 검색 결과를 가렸다. 그래서 메인 화면과 배너를 쌓은 바깥 스택에 `ignoresSafeArea(.keyboard)` 를 걸었다. 키보드가 배너를 밀지 말고 덮으라는 뜻이었다.

빌드도, 단위 테스트 215개도 통과했다. 시뮬레이터 캡처에서 걸렸다. 내 폰트 탭에서 미리보기 문구를 고치면 키보드 위에 편집 바가 떠야 하는데, 키보드만 있고 바가 없었다. 바깥 스택이 키보드 영역을 무시하자 그 안의 화면도 키보드 인셋을 받지 못했고, 키보드 위에 붙던 편집 바가 키보드 밑에 그려진 것이다.

고친 방법은 루트를 원래대로 두고 배너만 접는 것이다. `keyboardWillShow` 를 받으면 배너 자리의 높이를 0 으로 만들고, `keyboardWillHide` 에 되돌린다. 뷰를 지우지 않으니 다시 펴질 때 광고를 새로 요청하지도 않는다.

![미리보기 문구 편집 바가 키보드 바로 위에 떠 있다](/blog/superfont-ads-remove-ads/editor-bar-above-keyboard.png)

같은 캡처에서 함정이 하나 더 나왔다. 배너 전체를 감싼 컨테이너에 접근성 식별자를 걸었더니 그 안의 "광고 없이 쓰기" 버튼 식별자를 덮어서, UI 테스트가 버튼을 못 찾았다. 식별자는 배너 뷰 자체로 내렸다. 둘 다 새로 넣은 띠만 봐서는 안 보이고, 기존 화면의 키보드 상태와 자식 버튼을 같이 찍어야 드러난다.

## 시뮬레이터에서는 광고를 끈다

시간표 앱은 Debug 시뮬레이터에서 테스트 배너를 낸다. SuperFont 는 시뮬레이터 전부에서 끈다. UI 테스트, 스토어 스크린샷 캡처, 시각 확인이 전부 시뮬레이터에서 돌고, 처음 실행하면 동의 창과 ATT 창이 자동화를 막는다. 배너를 보고 싶을 때만 Debug 빌드에 `-showsAds` 를 준다.

## 남은 것

App Store Connect 에 상품을 만들어야 가격이 붙는다. 그 전까지 구매 버튼은 "결제하지 못했습니다" 를 띄운다. 앱 개인정보 답변도 "추적 안 함" 에서 기기 ID · 광고 데이터 · 대략적 위치를 추적에 쓰는 쪽으로 바꿔야 한다.
