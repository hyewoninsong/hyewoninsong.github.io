이제 VoiceOver 로 플래너의 일정을 읽고, 15분씩 옮기고, 길이를 바꾸고, 서랍에 넣고, 지울 수 있다. 손가락 문법이 전부였던 앱에 두 번째 문법을 만들지 않고 이 길을 냈다는 점이 이번 결정의 요지다.

## 블록 하나에 액션이 붙는다

그전에는 타임라인을 덮은 제스처 레이어 하나가 "타임라인" 이라는 요소 하나로 읽혔다. VoiceOver 는 그 한 칸에 갇혔고 블록의 시각도, 할 수 있는 일도 알 수 없었다. 이제 레이어는 요소가 아니고, 블록마다 요소가 있다. 라벨은 `제목, 시작–끝` 이고 value 는 완료 여부(이어진 묶음이면 "묶음에 이어짐" 까지)이며, 시간순으로 읽는다.

| 손가락 | 접근성 액션 |
|---|---|
| 왼쪽 체크 밴드 탭 | 완료로 표시 / 미완료로 표시 |
| 본체 탭 | 선택 / 선택 해제 |
| 하단 메모 버튼 | 메모 쓰기 |
| 본체 끌기 | 15분 앞으로 / 15분 뒤로 |
| 가장자리 끌기 | 길이 15분 늘리기 / 줄이기 |
| 서랍 버튼 위에 놓기 | 서랍에 넣기 |
| 삭제 버튼 | 삭제 |

이 밖에 몇 군데가 더 바뀌었다. 빈 시간에 일정을 만드는 길은 `빈 시간대` 요소 하나로, 두 번 탭하면 끌어서 만들 때와 같은 할일 선택 시트가 열린다. 오른쪽의 미니맵은 `하루 스크롤바` 라는 조절 요소가 돼서 위아래로 쓸면 한 시간씩 움직인다. 날짜 칸은 버튼이고, 선택 여부와 "오늘", "배치 있음" 을 말한다.

15분은 일부러 큰 단위다. 설정의 스냅 단위는 기본 5분인데, 액션 한 번에 5분이면 하루를 돌아다니기에 너무 잘다. 15분은 스냅 단위의 배수라 손가락으로 놓은 결과와도 어긋나지 않고, 더 가려면 같은 액션을 반복하면 된다. 모든 액션은 손가락 경로가 이미 부르는 스토어 호출을 그대로 부른다. 새 쓰기 길이 없으니 되돌리기, 알람 재예약, 텔레메트리가 똑같이 따라온다. 실행 뒤에는 결과를 한 줄로 읽어 준다.

## 왜 메뉴가 아니고 액션 세트인가

이 앱은 블록에 컨텍스트 메뉴도, 편집 시트도 달지 않기로 했었다. 그래서 대체 경로를 고르는 일이 곧 그 결정을 지킬 것이냐의 문제였다.

- **편집 시트나 컨텍스트 메뉴를 되살리기.** 가장 쉬운 길이지만 같은 조작이 손가락 문법과 메뉴, 두 벌이 된다. 한 벌이 바뀔 때마다 다른 한 벌이 어긋난다. 접근성 액션은 화면에 새 UI 를 더하지 않는 보조 경로라 이미 거절한 결정과 부딪히지 않는다.
- **제스처 레이어를 그대로 두고 라벨만 달기.** 읽을 수는 있어도 아무것도 할 수 없다. 일정이 "있다" 는 것만 아는 앱은 쓸 수 있는 앱이 아니다.
- **삭제에 확인 창을 거치기.** VoiceOver 에서 경고창은 한 걸음 더 먼 길이다. 삭제는 되돌리기 스택에 있으니 결과를 알리고 되돌리기에 맡겼다.

글자 크기도 같은 방식으로 정했다. 한 시간이 80pt 로 고정이고 하루의 세로 비례(1분 = 4/3pt)가 타임라인의 정체성이라, 블록 높이를 글자에 맞춰 키울 수는 없다. 그래서 Dynamic Type 은 따르되 시간축 글자와 날짜 칸은 1.3배, 블록 안 제목·메모는 1.15배에서 멈춘다. 블록 안에 몇 줄이 들어가는지 세는 계산도 같은 배율의 글자 높이를 읽는다. 그림과 셈이 어긋나면 마지막 줄이 잘리기 때문이다.

## 동작 줄이기는 이동만 끈다

시스템의 동작 줄이기를 켜도 서랍 고스트는 날고, 블록은 미끄러지고, 잠금 자물쇠는 흔들렸다. 앱에 `accessibilityReduceMotion` 을 읽는 곳이 하나도 없었다. 연출마다 따로 분기하면 새 연출을 만들 때 잊게 되니, 한 곳(`MotionPreference`)을 거치게 했다.

정책은 이렇다. 이동, 비행, 스프링, 흔들기는 즉시 처리하거나 0.15초 크로스페이드로 바꾼다. 색과 투명도 변화, 햅틱은 그대로 둔다. 손가락을 따라가는 드래그 프리뷰는 원래 애니메이션이 없어서 영향이 없다.

- 서랍 넣기·꺼내기는 고스트 없이 도착 처리(말풍선, 햅틱)만 하고 블록이 바로 사라지거나 나타난다.
- 블록 재배치와 미니맵 막대는 즉시 제자리로 간다.
- 자물쇠는 흔들지 않고 한 번 깜빡인다.
- 튜토리얼의 반복 손가락 데모는 멈춘 힌트가 된다. 손가락은 목표 자리에 서 있고 강조 테두리만 남는다.

애니메이션을 전부 끄는 안은 버렸다. 어지럼은 움직임에서 오지 색 전환에서 오지 않는데, 전부 끄면 완료 체크가 켜지거나 선택이 바뀌는 순간까지 사라져 상태 변화를 알아볼 단서가 줄어든다. 앱 설정에 별도 토글을 두는 안도 버렸다. 시스템 설정이 이미 있고, 둘이 어긋나면 혼란만 는다.

## 아직 남은 것

시뮬레이터의 UI 테스트는 커스텀 액션을 돌리지 못한다. 실기기 VoiceOver 로 읽는 순서와 액션 목록을 한 번 확인해야 한다. 묶음 칩과 연결 버튼, 곧 블록을 이어 붙이는 조작의 액션은 이번 범위 밖이라 아직 없다. 스플래시와 색 고르기 같은 나머지 애니메이션도 후속이다.
