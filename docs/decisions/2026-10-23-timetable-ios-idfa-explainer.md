# SuperTimetable iOS — ATT 앞에 IDFA 안내 화면을 둔다

**2026-10-23**

- 결정: AdMob "IDFA 설명" 메시지(SuperTimetable IDFA)를 iOS 앱에 붙인다. UMP 가 안내 화면 한 장 → 시스템 ATT 창을 이어서 띄운다. 앱 코드는 그대로이고, 앱이 직접 부르는 ATT 는 이미 답한 상태라 지나간다.
- 이유: 튜토리얼 직후 이유 없이 ATT 창이 뜨면 사용자가 무엇을 고르는지 모른 채 거절한다. 이유부터 알려 주는 쪽이 정직하고 허용 비율도 오른다.
- 진 대안: 안내 없이 ATT 만 (화면 한 장이 적지만 맥락이 없다) · 앱 디자인으로 직접 만든 안내 화면 (결은 맞지만 코드·빌드가 필요 — 나중에 바꿀 수 있다).
- 문구: ko·en 은 직접 다듬어 "허용하지 않아도 앱은 똑같이 쓸 수 있다" 를 넣었다. ja·zh-Hans·zh-Hant·es·fr·pt-BR 은 Google 기본 번역.
- 방침: 3절에 안내 화면 한 줄을 더했다. 끄면 이 줄도 뺀다.
